# Requesting the Full Corpus

The full corpus is available **on request for non-commercial research use**. It includes:

- the annotation layer (entity and relation annotations)
- the schema and annotation guidelines
- the predefined train/validation/test splits
- the training-ready NER and RE files

The underlying article text remains subject to the licenses of the original publishers.

## How to request

Send an e-mail to **mojtabamoradi2013@gmail.com** with the subject line:

```
[Corpus Request] Multi-Domain Scientific NER+RE Corpus
```

Include the following:

```text
Full name:
Position (student / researcher / faculty / other):
Institution / organization:
Institutional e-mail address:
Supervisor (for students):
Intended use (2–3 sentences):
Parts requested:  [ ] annotation layer   [ ] NER training files   [ ] RE training files   [ ] all
I confirm that:
  [ ] the data will be used for non-commercial research only;
  [ ] I will not redistribute the data; others should request it through this procedure;
  [ ] I will cite the paper in any publication that uses the data.
```

Please send the request from an institutional e-mail address. We aim to reply within a few working days.
